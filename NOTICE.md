# Source and attribution

Novel Graph Lab was extracted and adapted from the author's [Novel KG Studio](https://github.com/fuxiaoji/novel-kg-studio) research dashboard, specifically its embedded graph and saved question records.

`examples/demo.json` records the original dashboard filename and SHA-256. It preserves historical entity names, relationships, excerpts and answers. Inconsistent names or historical mistakes are not silently presented as newly verified facts. The original full novel and complete retrieval logs are not included.

The MIT license applies to application code and original project documentation. Literary quotations embedded in historical records remain attributed source material; their inclusion does not assert new authorship or extend the code license to underlying literary works. No license is granted here to novels subsequently imported by users.

The design process used the [Anthropic frontend-design skill](https://github.com/anthropics/skills/tree/main/skills/frontend-design) as guidance. That skill is not bundled here. Excalidraw and LightRAG README structures were studied as references, not copied as project claims. There is no affiliation or endorsement.
