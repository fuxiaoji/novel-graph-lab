# Interface direction

The product is a reading and evidence workspace. The graph is the primary document; controls should feel like a quiet set of reading tools.

Palette: chalk `#f7f8fa`, paper `#ffffff`, ink `#252b37`, slate `#536b83`, sage `#557968`, ochre `#a97a3f`. No decorative gradients. Muted entity colors remain meaningful and consistent.

Typography: locally available Palatino / Iowan Old Style / Song typefaces for the book title and quotations; system sans-serif for controls. Proportional numerals and sentence-case labels. No external font requests.

Layout: compact book/query column; a wide central graph sheet with graph-wide statistics above it; a source-reading column. The graph is the visual focus, not a stack of metric cards. Export and display settings stay available but secondary. Align paragraphs left and keep lines short.

Self-critique before implementation: a cream background, terracotta accent and newspaper rules would repeat another common generated design. Use cooler paper, a restrained slate action color, an actual reading hierarchy, and soft sheet boundaries. Remove decorative all-caps labels, numbered sidebar categories, the star icon, neon pulses and the perspective floor.
